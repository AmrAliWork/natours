# Natours Backend

A backend-focused web application built with **Node.js, Express.js, MongoDB, and Mongoose**, based on the Natours project from Jonas Schmedtmann's Node.js course.

## Features

- Authentication & Authorization with JWT
- Password Reset
- User & Tour Management
- Reviews & Ratings
- Advanced API Features
- Stripe Payment Integration
- Email Service with Resend
- Error Handling
- CORS

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Stripe
- Resend
- Pug

> The frontend UI is based on the original course project. My main focus was backend development.
